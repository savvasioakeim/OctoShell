Questions, answered.

The short version — no sales deck.

What does “BYOK” actually mean?+

Bring Your Own Key. You plug in your own Anthropic (or other) API key, or sign in to the local claude CLI. OctoShell never proxies your traffic — you pay the provider directly at raw token cost, with zero markup.

Does my code leave my machine?+

Only what you choose to send to your model provider in a prompt. There's no OctoShell cloud, no telemetry, and no account — the app runs entirely as a native Windows process.

Why Tauri instead of Electron?+

Tauri uses the OS WebView plus a Rust core, so the binary is a fraction of an Electron app's size and idles at a fraction of the RAM — while the terminal, PTY and parsing all run in native Rust.

Is it really free?+

Yes — open source under MIT. Clone it, fork it, ship your own build. The only thing you ever pay for is your own model usage.
