REVIEW AND QA

06 · A review pass before it reaches you

When an agent hits a test failure it reads the error, rewrites the file, and runs the tests again on its own. You can also turn on a review agent that reads each change first and flags anything worth a second look. When it looks good, QA mode starts your app's dev server for you so you can click through the change and accept it or send it back.

OUR PHILOSOPHY

Built on open source principles

OctoShell aims to be transparent, light, and fully under your control. No account to create, no telemetry, nothing hidden.

Open source, yours to keep

Licensed under MIT. The code is open and readable, and yours to fork, change, or self host for as long as you like.

Your agents, your keys

Sign in with the Claude Code or Gemini CLI you already use, no API key required. Bring your own key if you prefer, and you pay the provider directly. You can also run local models through Ollama at no token cost.

Runs locally, stays private

Your code context never leaves your machine. Agents run, files change, and Git worktrees live entirely in your local environment.

Light and native on Windows

Built with Rust and Tauri, so it stays light on memory and starts quickly. The terminal, PTY, and parsing run in native Rust, and it feels at home on Windows.

Questions, answered.

The short version, no sales deck.

What does “BYOK” actually mean?+

Bring Your Own Key. You plug in your own Anthropic (or other) API key, or sign in to the local claude CLI. OctoShell never proxies your traffic. You pay the provider directly at token cost.

Does my code leave my machine?+

Only what you choose to send to your model provider in a prompt. There's no OctoShell cloud, no telemetry, and no account. The app runs entirely as a native Windows process.

Why Tauri?+

Tauri uses the operating system WebView plus a Rust core, so the download stays small and idle memory stays low. The terminal, PTY, and parsing run in native Rust.

Which agents can it drive?+

Claude and Gemini directly, plus Codex, Cursor, Copilot, and OpenCode through the Agent Client Protocol. You can also run local models with Ollama. Pick a different one per agent, orchestrator, or reviewer if you like.

What is QA mode?+

Once agents finish, OctoShell can start your app's dev server for you and open it, so you can click through the change and either accept it or send it back with notes. You never juggle terminals to run the app yourself.

Is it really free?+

Yes. Open source under MIT. Clone it, fork it, ship your own build. The only thing you pay for is your own model usage.
